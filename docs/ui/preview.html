目标：只换皮肤不动骨架。内容条目、显示顺序、文案、数据源一字不改；直角 + 1px 发丝线、 单一强调色（蓝）、语义色只给档位与告警、去 emoji。overlay 画面优先——不靠降透明度， 靠缩小占屏面积。下面所有窗口均为 1:1 像素，字体族与 Tk 一致，可与真实渲染逐项对齐。

§2　游戏内 Overlay（1:1，236px 宽）

三个要点：① 档位逐行分色 + 15px 徽章（现状整块被第一张的档位色涂满，S/A/B 看不出差别，是真 bug）； ② 去 emoji（🧠⟳⏳⚠ 全是彩色字形，是"干扰游戏元素"的主要来源）； ③ 高度贴内容，不再强撑 560px 下限。

④ 删掉「路线: AD」整行——路线不是 ad/ap/坦克三键，而是不同装备玩法（同一路 AD 里也有多种出法）， 拿伤害类型键当"路线"显示既没用又与系统自身的方案制矛盾。具名方案目前只喂给模型当语境、未进 UI， 所以这行直接去掉；current_path 本身仍留在引擎里用于选候选与复盘，只是不再显示。 主窗口状态行同步去掉。
